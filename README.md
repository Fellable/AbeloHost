# AbeloHost Blog Test Assignment

Реализация тестового задания Рыбцова Евгения.

Простой блог на чистом PHP с категориями и статьями. Проект реализован без PHP-фреймворков, чтобы основная логика маршрутизации, работы с базой данных и формирования страниц оставалась явной.

## Возможности

- главная страница с категориями и тремя последними статьями в каждой;
- страница категории со статьями, сортировкой по дате или просмотрам и пагинацией;
- страница статьи с полноразмерным изображением, категориями и счётчиком просмотров;
- три похожие статьи с общими категориями;
- страница 404 для неизвестных адресов;
- SQL-скрипты для создания таблиц и заполнения тестовыми данными;
- адаптивные стили на SCSS;
- статический анализ PHPStan.

## Стек

- PHP 8.1+
- MySQL 8
- Smarty 5
- SCSS / Dart Sass
- Nginx
- Docker Compose

## Запуск

1. Создать локальный файл окружения:

   ```powershell
   Copy-Item .env.example .env
   ```

2. Собрать и запустить контейнеры:

   ```powershell
   docker compose up --build -d
   ```

3. Установить PHP-зависимости:

   ```powershell
   docker compose exec php composer install
   ```

4. Создать таблицы:

   ```powershell
   $OutputEncoding = [System.Text.UTF8Encoding]::new($false)
   Get-Content database/migrations/001_create_blog_tables.sql -Encoding UTF8 -Raw |
       docker compose exec -T mysql sh -c 'mysql -u"$MYSQL_USER" -p"$MYSQL_PASSWORD" "$MYSQL_DATABASE"'
   ```

5. Заполнить базу тестовыми данными:

   ```powershell
   $OutputEncoding = [System.Text.UTF8Encoding]::new($false)
   Get-Content database/seeders/001_seed_blog.sql -Encoding UTF8 -Raw |
       docker compose exec -T mysql sh -c 'mysql -u"$MYSQL_USER" -p"$MYSQL_PASSWORD" "$MYSQL_DATABASE"'
   ```

6. Открыть <http://localhost:8080>.

SQL-скрипты выполняются вручную и отдельно друг от друга: миграция создаёт структуру базы, а сидер добавляет демонстрационные данные.

## Примеры страниц

- главная страница: <http://localhost:8080/>;
- категория: <http://localhost:8080/categories/photo-hosting>;
- сортировка: <http://localhost:8080/categories/photo-hosting?sort=views>;
- пагинация: <http://localhost:8080/categories/photo-hosting?sort=date&page=2>.

Ссылки на статьи доступны на главной странице и странице категории.

## Стили

Собранный CSS хранится в репозитории, поэтому Node.js для обычного запуска не требуется. После изменения SCSS нужно:

```powershell
npm install
npm run build:css
```

Исходники находятся в `resources/scss`, результат сборки — в `public/assets/css`.

## Статический анализ

```powershell
docker compose exec php composer analyse
```

PHPStan проверяет код приложения, конфигурацию, маршруты, со средней строгостью 5/10.

## Реализация и как бы я делал дальше

Все запросы проходят через `public/index.php`. Маршруты описаны обычным массивом в `routes/web.php`, после чего небольшой Router определяет контроллер и действие.
Похожие статьи должны иметь хотя бы одну общую категорию с текущей. Текущая статья исключается, результаты сортируются сначала по количеству общих категорий, затем по дате публикации, после чего выбираются три записи. Увеличение количества просмотров выполняется отдельным SQL-запросом.

В случае дальнейшего развития именно этого репозитория, я бы сделал DI или Application (по типу как в ларавеле), вынес всё в сервисы (CategoryService как пример), по мере необходимости ввёл бы интерфейсы и трейты, сейчас её нет. Миграции, а не простое создание выполнение команд из консоли. Далее - очереди, джобы. CRUD, разумеется. В такое зайдёт декоратор с кешированием. 

## Использование ИИ

При выполнении задания использовался ИИ как вспомогательный инструмент: подготовки черновых вариантов кода и SQL, картинок, css, а также проверки Docker-конфигурации и статического анализа. Архитектурные решения, проверка и правка результатов выполнялись мной.
